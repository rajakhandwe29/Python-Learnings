## 💡 Interview Tips

### During Coding Interview
1. **Read carefully** - Understand the problem
2. **Ask questions** - Clarify requirements
3. **Plan first** - Think before coding
4. **Test cases** - Consider edge cases
5. **Explain thinking** - Talk while solving
6. **Optimize** - After it works, make it better

### Communication
- **Explain approach** before coding
- **Talk through** your solution
- **Mention trade-offs** - Time vs space
- **Ask feedback** - "Is this approach good?"
- **Stay confident** - Even if you're not

### Common Mistakes to Avoid
- ❌ Starting to code immediately
- ❌ Not considering edge cases
- ❌ Forgetting to handle errors
- ❌ Over-complicating solution
- ❌ Not testing before submitting
